# Curious Kitchen

A student-friendly Python/Flask web application that helps users discover recipes from available ingredients, learn food science, reduce food waste, and test kitchen knowledge.

## Run locally

1. Install Python.
2. Open a terminal in this folder.
3. Install Flask:
   `pip install flask`
4. Run:
   `python app.py`
5. Open `http://127.0.0.1:5000` in a browser.

## Project structure

- `app.py` — Python/Flask application and recipe data
- `templates/` — HTML pages
- `static/style.css` — styling
- `static/script.js` — small interactive feature

## Competition explanation

Problem: People may have ingredients at home but not know what to make, while young learners may not understand the science and safety behind cooking.

Solution: Curious Kitchen recommends recipes from available ingredients, explains food science, suggests ways to reduce food waste, and provides a learning quiz.
